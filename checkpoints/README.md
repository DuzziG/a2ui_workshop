# Checkpoints

Each folder holds the complete `lib/` folder of the app at the **end** of that step of the [workshop](../README.md).

Fell behind? Copy a checkpoint's `lib/` over your own. Your `lib/api_key.dart` isn't in the checkpoints, so copying never overwrites your key.

The checkpoints build the example app, Potion Lab. Once you've caught up, put your own idea back in: your persona, your functions and your components.

| Folder | The app after this step |
| ------ | ----------------------- |
| `step_03` | App shell, chatting with Gemini in text |
| `step_04` | A hand-written surface next to Gemini's answer |
| `step_05` | Hand-written data binding and actions |
| `step_06` | Gemini writes the UI, with the X-ray view |
| `step_07` | A persona |
| `step_08` | Photos |
| `step_09` | Actions go back to Gemini |
| `step_10` | Functions Gemini calls |
| `step_11` | Your own component |
| `step_12` | Streaming |
| `bonus_a` | AI-painted illustrations |
| `bonus_b` | A 3D companion (needs `flutter pub add flutter_scene vector_math`) |

All the other packages are added in Step 2.
